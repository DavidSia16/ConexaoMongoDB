# Java + MongoDB CRUD

Projeto prático em Java desenvolvido para aprender a integração com o banco NoSQL MongoDB Atlas.

##  Tecnologias 
- Java 17
- Maven
- MongoDB Java Driver (org.mongodb)
- BSON

##  Funcionalidades
- Conexão segura com cluster MongoDB Atlas
- Mapeamento de objetos Java para BSON Documents
- Operações de CRUD (Create, Read, Update, Delete) em coleção de veículos
